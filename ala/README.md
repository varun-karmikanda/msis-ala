# creating venv

## Linux

### Creating venv

```
python3 -m venv venv
```

### Activating venv
```
source venv/bin/activate
```
```
. venv/bin/activate
```
---

## Windows (powershell)

### Creating venv

```
python3 -m venv venv
```

### Activating venv
```
venv\Scripts\Activate.ps1
```
